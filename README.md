# Cyst Happens

A responsive, static ovarian health education and symptom journaling website.

## Run
Open `index.html` in a browser. No build process, accounts, API keys, or database are required.

## Publish using GitHub Pages
1. Create a public repository on GitHub.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch** and choose `main` / `(root)`.
5. Save and wait for GitHub to display the public website address.

## Important medical limitations
This is a **prototype** for education and symptom documentation, not a validated clinical assessment or diagnostic instrument. The displayed percentage is the proportion of 17 predefined symptom flags selected, not the likelihood of any ovarian condition. A value below 50% does not indicate safety. Emergency messages override the playful results message. Clinical review and usability testing are necessary before presenting this to patients as medical guidance.

## Privacy
Answers are held in JavaScript memory only. No external fonts, analytics, tracking, API requests, or remote data storage. Closing or refreshing the page clears answers. Downloaded reports are plain text.

## Notes
The form includes the 29 questions supplied by the user. The contraception question is worded neutrally because not all IUDs are hormonal. The checkbox 'None' choices are mutually exclusive with symptom selections. The site supports reduced-motion preferences.
